# Download games from the cabinet's ROMs project

Open **T3 Code → arcade cabinet → ROMs**. This project's folder is `/roms`.
Send a task in ordinary language, for example:

> Download Gunstar Heroes for Genesis onto this cabinet. Wait until it is
> ready and verify the installed game. Don't launch it yet.

Or:

> Download Contra for NES, verify it, and launch it on the cabinet.

The agent can do the whole task **from this project on the cabinet**.
The CLI is installed and the server connection is configured. Downloads run
on the server, then arrive here automatically.

**Start here:** [ROM-DOWNLOADS.md](ROM-DOWNLOADS.md)

**Agent instructions:** [AGENTS.md](AGENTS.md)

**Reusable skill:** [skills/arcade-roms/SKILL.md](skills/arcade-roms/SKILL.md)
(also linked as `SKILL.md` at the project root).

Installed games live in the system folders below this directory and appear
in Pegasus on the cabinet. Documentation files are not games and are not
included in its collections.
